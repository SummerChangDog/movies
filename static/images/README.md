## 获取图片资源

### Logo图片来源：
- 豆瓣Logo：可从豆瓣官网获取
- IMDb Logo：可从IMDb官网获取
- 烂番茄Logo：可从烂番茄官网获取

### 注意事项：
1. 所有Logo图片应使用透明背景的PNG格式
2. 图片大小应适中，避免过大影响加载速度
3. 请确保使用的Logo符合各平台的使用规范

### 临时解决方案：
如果暂时没有Logo图片，可以使用文字代替，修改HTML中的相关代码。
